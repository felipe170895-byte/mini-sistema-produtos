# Mini Sistema de Gestão de Produtos

## Descrição

Este projeto consiste em um mini sistema acadêmico de gestão de produtos, desenvolvido em PHP puro, MySQL, PDO, HTML, CSS, Bootstrap, JavaScript e AJAX.

O sistema permitirá cadastro de usuários, autenticação, cadastro de fornecedores, cadastro de produtos, criação de cesta de produtos e atualização de dados utilizando AJAX.

## Tecnologias utilizadas

- PHP
- MySQL
- PDO
- HTML
- CSS
- Bootstrap
- JavaScript
- AJAX
- Git e GitHub
